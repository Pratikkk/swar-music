# Welcome guide

New installations with an empty library open a three-step guide after the library has initialized:

1. Choose a music folder, including subfolders. The guide shows scan progress, song totals, and import errors. Scanning continues if the guide is closed.
2. Learn where to browse/search, create playlists, drag songs, and save favourites.
3. Learn playback, queue, output selection, expanded Now Playing, and Settings.

Continue does not require a folder. Not Now, Escape, and Start Listening remember dismissal in `welcomeGuideCompleted`. Help → Welcome Guide always reopens the guide from the library window. Existing watched folders or tracks suppress automatic onboarding on upgrade. Existing macOS app data survives reinstalling the app, so reinstalling alone does not reset the guide.

No music is copied or moved, no permissions are expanded, and the guide uses the same read-only folder importer and scanner as the rest of the app.
