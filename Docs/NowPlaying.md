# Expanded Now Playing

Click the floating player's artwork or song details, or use ⇧⌘N, to open the expanded player. Escape or the collapse button returns to the library. The sheet is 650 points high and follows the window width between 640 and 900 points.

Settings → Now Playing, or the palette button in the expanded player, offers Artwork or Neutral backgrounds, blur strength from 20–100% (default 70%), and Show technical details (default on). Changes apply live and persist in app preferences. Neutral mode and missing artwork use the appearance-aware base without creating a blurred layer. Reduce Transparency also uses the neutral base and disables the blur control, retaining the saved blur for later. Blur values are bounded and non-finite stored values fall back to 70%. Hiding technical details removes the format/signal-path chip from this player; playback errors, session notices, and output-device controls remain available. Library quality badges keep their existing behavior. Artwork and metadata use short crossfades that respect Reduce Motion; artwork decoding reuses the existing bounded thumbnail cache. Presentation retains fixed title and status slots and, when enabled, a quality-chip slot so transport controls do not move as songs change. No new playback or volume polling is added.

The hierarchy is artwork, title, clickable artist/album, audio-quality chip, and a reserved area for warnings. Artist and album links dismiss the sheet and browse matching library results in the appropriate search field. Errors and session notices remain available, with long messages exposed through help and selection. Ordinary play/pause state is shown only by the transport button. The Playing, Paused, and Ready to resume text is absent; an always-present fixed-height warning container prevents that area from collapsing when empty.

The fixed controls area contains elapsed and remaining time, a wide seek slider, a reserved Seek to time preview during dragging with the standard slider (the waveform uses a pointer timestamp), Shuffle, Previous, Play/Pause, Next, the same cycling Repeat button as the floating player, volume, and the output device name. A seek targets the song on which the gesture began and is discarded if the song changes or a conflicting operation starts. The sleep timer remains in the header.

Up Next sits beside the artwork at widths of at least 800 points. At narrower widths it replaces the artwork area while the complete playback controls remain visible below. Queue rows retain artwork, reordering, removal, and playback actions. The queue list background is transparent over its panel.

Validation: 101 package tests in 13 suites passed and the Debug build succeeded. Manual checks covered the restored paused state, a single Resume control, artist/album navigation, click-to-seek and accessibility seeking, wide and narrow queue layouts, and restoring the window size. The existing song remained paused, its position was restored to approximately eight seconds, and output volume was preserved. The seek preview and crossfades are implemented; pointer dragging, live song transitions, dark appearance, and accessibility preference changes were not separately verified in this pass. Hardware audio behavior is unchanged.

Customization validation: Debug build and 111 package tests pass. UI checks covered the neutral background, blur adjustment, shared settings/popover values, format-chip visibility on a loaded track, and saved preferences after relaunch. Default Artwork/70%/details-on choices were restored after checking. A brief resume/pause check left the existing song paused at approximately 18 seconds. Reduce Transparency uses an environment-driven fallback; changing the system accessibility preference was not part of manual QA.
